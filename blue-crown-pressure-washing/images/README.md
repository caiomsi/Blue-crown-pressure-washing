# Images Needed

Drop real photos here and update the `src` attributes in `index.html` to match.

## Required Images

| Filename | Dimensions | Content |
|---|---|---|
| `hero-pressure-washing.jpg` | 1920×1080 | Action shot: pressure washer cleaning a driveway or house exterior |
| `driveway-before.jpg` | 600×400 | Driveway with oil stains, tire marks, or heavy grime |
| `driveway-after.jpg` | 600×400 | Same driveway after cleaning — clean concrete |
| `house-before.jpg` | 600×400 | House siding with visible mold or mildew |
| `house-after.jpg` | 600×400 | Same house siding after soft wash — bright and clean |
| `roof-before.jpg` | 600×400 | Roof with black algae streaks |
| `roof-after.jpg` | 600×400 | Same roof after soft wash — clean shingles |
| `og-image.jpg` | 1200×630 | Branded social share image (logo + tagline on a clean background) |
| `storefront.jpg` | 800×600 | Truck or team photo for schema markup |

## Image SEO Notes

- File names are already optimized (descriptive, hyphenated, location-aware)
- `alt` attributes are already set in `index.html` — update them if the actual photo subject differs
- Compress all images before upload — target under 200KB each (use squoosh.app or TinyPNG)
- Consider WebP format for best performance; add a JPEG fallback

## Photo Tips for Best Conversion

Before/after pairs are the single highest-converting content for a pressure washing website.
Take them from the same angle, same time of day. Even phone photos work well if lighting is good.
